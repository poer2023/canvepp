## Pinterest 与搜索边界

素材页默认显示官网；已有浏览器 OAuth / 原生收藏入口保留。两者登录存储独立，不读取本机浏览器 Cookie，也不声称授权后网页自动登录。WebView 标记 Untrusted，网页无 Go/RPC 本机桥接；导入消息要求 Pinterest 来源、真实点击、合法 Pin 及图片地址，目标画布在点击时捕获。

本轮实际官网加载和窄窗口浏览通过；继续浏览触发 Pinterest 登录门槛。沿用用户“跳过账号验收”的选择，没有填写凭据、没有把登录页当作个人收藏导入通过。网页导入消息校验通过自动化；真实账号收藏与 Pin 导入仍待登录后的实际验收。
