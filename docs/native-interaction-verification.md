# Canvepp Native 0.4.1 · 交互修复验收

日期：2026-11-06。环境：macOS arm64 / Apple M4。范围见 [交互验收合同](native-interaction-acceptance.md)。

已安装并打开 `/Users/hao/Applications/Canvepp Native.app`，版本为 0.4.1，安装后二进制与本轮构建一致，`codesign --verify --deep --strict` 通过。

## 修复及验证

1. **滚动缩放**：画布上的鼠标滚轮和触控板纵向滚动均以指针为锚点缩放；触控板使用较低灵敏度。保留捏合缩放、空格/中键拖动平移。左侧历史和参数区域继续独立滚动。
2. **缩放按钮**：之前自定义画布输入处理器位于按钮父节点，会先截获鼠标按下，将其当作框选；辅助功能直接调用按钮动作绕过了此问题。现在输入画面与悬浮按钮处于同级。正式包真实鼠标点击验证 `31% → 39% → 31%`，滚动到 `40%`，点击适应回到 `25%`；选图后的缩放保持左侧提示词和选区。
3. **左侧反馈**：标签、比例、生成张数、常用按钮采用 120 ms 颜色过渡及 100 ms 轻微按压反馈；面板切换为 140 ms 轻微淡入，提示词输入框有聚焦反馈。系统开启减少动态效果时跳过这些动效。测试验证交互立即生效，动效结束后没有待绘制帧。
4. **性能**：长连线改为有界、亚像素误差的 GPU 线段绘制，避免每次缩放栅格化大面积透明蒙版；多选设置读取复用选区身份，不逐帧复制整组节点；同一图片内无状态变化的鼠标移动不主动要求重绘。

## 同场景测量

20 张卡片的原画布副本，约 75%–183% 缩放范围，16 次相同缩放命令。指标包含 MyGo 帧构建、布局、绘制和 GPU present 提交，不是显示器的持续 FPS。

| 项目 | 0.4.0 | 0.4.1 修复包 |
| --- | ---: | ---: |
| 连续缩放中位帧耗时 | 2.9 ms | 1.1 ms |
| 连续缩放 p95 | 11.2 ms | 1.7 ms |
| 连续缩放最大帧耗时 | 12.0 ms | 8.5 ms |
| 缩放采样单帧最大进程分配量 | 21,971.9 KB | 11,943.3 KB |

六次真实鼠标拖动也已复测，常规帧中位值为 1.4 ms。该组包含首次打开设置面板：修复前 p95 为 9.7 ms、最大 16.1 ms，修复后 p95 为 10.7 ms、最大 15.2 ms，**不能据此声称所有拖动峰值都降低了**。首次字体布局及 GPU 资源准备仍有开销。

500 张选区的设置同步基准为约 2.874 μs/op、0 B/op、0 allocs/op。连线细分测试覆盖大跨度、回折和纵向连接，误差不超过 0.4 逻辑像素，使用固定缓冲区且不分配临时内存。

证据：[性能采样](../artifacts/native-interaction-20261106/performance.json)、[选区基准](../artifacts/native-interaction-20261106/selection-benchmark.txt)。这些是本机短时样本，不代表长期高刷表现或所有图片规模。
