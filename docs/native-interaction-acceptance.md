# 原生交互修复验收 · 2026-11-06

范围：已安装的 Canvepp Native 左右结构；不修改旧 Web 版或原图片内容。

- 右侧画布：鼠标滚轮、触控板纵向滚动均围绕指针缩放，捏合仍可缩放；空格拖动和中键拖动平移。左侧长列表/参数区继续正常滚动，不联动画布。
- 右下角缩小、放大、适应按钮：真实鼠标点击和键盘触发均有效，不触发框选、清空选区或拖动；缩放范围 5%–400%，百分比及时更新。
- 左侧：标签、比例、生成数量和常用按钮加入约 100–160 ms 的悬停/按下/选中反馈，切换有轻微过渡；尊重系统减少动态效果，空闲时停止绘制，不增加常驻动效。
- 性能：定位真实交互中的耗时，比较同一画布在连续滚轮缩放、拖动及左侧切换时的帧耗时和分配。修复应保留清晰度、透明通道、连线与全部内容，不能只凭小场景基准宣称无卡顿。
- 数据：使用副本做交互和性能测试；更新安装前正常退出并完成保存，保留可回退版本。原始库不重置、不重新导入覆盖。
- 检查：事件路由回归测试、缩放锚点/边界、按钮与文本快捷键隔离、动效静止/减少动态效果、Go race/vet，最后在正式安装包上用真实鼠标验收。

已复现：辅助功能直接触发「＋」能从 25% 到 31%，实际坐标点击同一按钮无变化。代码将精确滚动事件路由为平移，需要统一为缩放。完成后将实测与限制写入验收记录。
