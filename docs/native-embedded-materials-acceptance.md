# 素材库进入主窗口右侧 · 0.6.2

目标：Pinterest、Eagle、连接设置及素材大图预览直接显示在主窗口右侧内容区，取消独立素材窗口。沿用用户已确认的原生界面与浏览器授权方式。

- 结构：保留左侧画布 / 历史 / 回收站与底部入口；右侧素材页提供返回画布、Pinterest / Eagle 切换和当前导入目标。连接设置、大图预览在右侧页内切换，Esc 逐层返回。
- 状态：切换到设置、画布、历史、回收站时关闭素材页展示，但保留素材连接、筛选及已加载页面；返回画布保留位置、选择、提示词和内容。异步导入仍写入点击时的画布；授权完成激活主窗口并打开 Pinterest 页。
- 视觉：复用现有白 / 浅灰主内容面板，不增加常驻顶栏或遮罩。图标操作沿用悬停提示；最小主窗口 1000×680 可操作，1440×900 充分利用右侧空间。
- 验证：原生布局测试确认素材控件均在左侧栏右方、所有入口和返回有效；实际隔离窗口检查两种尺寸、Pinterest 设置 / 图板 / 预览 / 导入、Eagle 未连接状态及浏览器回调只返回主窗口。生产更新前备份，比对画布内容、素材和历史；真实 Pinterest 账户验收仍由用户稍后填写凭据。
- 范围外：不改变 Eagle API、Pinterest 权限 / 密钥存储、生成模型或助手独立输入条；不触发真实生图，不修改真实收藏。

## 0.6.6 画布和右栏验收

- 在 Windows 安装版打开已登录的 Pinterest 收藏，页面右侧和底部与面板齐平。网页可滚动时使用 2 pt 自绘滑块，靠近边缘、滚动或拖动时可见，移开后自动隐藏。改变右栏宽度后再检查边缘和拖动。
- 画布保留指针锚点。常规 Windows 鼠标从 100% 向上滚一格约为 106%，反向一格回到起点。高精度触控板连续输入可作更小的调整。
- 对有图片的画布执行「在文件管理器中显示」，同目录可见画布描述和原图资源。文件中的相对路径可随目录搬移，重复显示后与当前节点及其图片版本一致。
