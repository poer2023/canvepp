# Native assistant and materials · 0.6.0

## 像素动效与跨应用唤起

- 助手输入与工具共用一整块随明暗变化的工作面。像素动效贴合窗沿并读取系统强调色，正文和工具的尺寸固定。亮暗两种主题均可辨认文本、焦点、附件和发送状态。
- 打开时播放一次约半秒的点阵动画，首次从空白开始输入时给短反馈。系统开启「减少动态效果」时使用静帧。空闲或窗口隐藏后停止调度动画帧。
- 保留既有的自动聚焦、输入法、换行、附件、草稿及 Esc 路径。使用独立资料库和本地测试构建验证，跨应用三击需要记录系统事件识别和可见浮窗。

本机最终构建实测收到三组按下与抬起，整段序列 615 ms。系统监听匹配后，应用在 14 ms 内报告窗口可见，随后通过窗口截图确认是一体版助手。测试进程已退出。单元测试核对唤起动画、输入反馈、减少动态效果和静止后停止绘制。

## ASCII 工作面、画布选择与拖动

- 以[确认过的光影小样](../artifacts/ascii-motion-study-20261119/character-relief.gif)为准。固定网格上的字符随曲面起伏改变密度和明暗，横跨整块工作面。跟随工作区的浅色与深色，正文、光标和线性操作图标在动效上仍清晰可辨。
- 聚焦时持续播放 4.5 秒循环，每秒调度最多 12 次绘制，缓存字形，绘制帧复用视图。失焦、隐藏和系统「减少动态效果」时停止调度，显示静态光影。
- 从顶栏名称打开画布菜单，鼠标与键盘可选择目标。菜单标记当前选择且过滤回收站画布。切换后保留草稿、附件和主窗口当前画布，发送与查看会话使用选中的画布。手动指定在本次运行中保留，也可恢复空白打开时跟随当前画布。
- 从其他应用唤起、重复唤起与选好画布后，能直接键入正文。正文整行含两侧留白都可点击和选字，悬停时无独立灰底和气泡。顶栏标题、顶栏留白和底栏留白可拖动窗口。用隔离资料库在 macOS 实机核对焦点和实际显示，保留一个可试用的预览实例。

## Gate 1 — 助手输入
- 可见关闭按钮及 Esc 隐藏；关闭保留草稿与附件，发送中关闭不重复提交。
- 无占位符，原生文本输入随换行及自动折行增高，达到上限后内部滚动。Enter 发送、Shift+Enter 换行，兼容输入法。
- 窗口隐藏时停止装饰重绘。可选择或拖入图片、文件，附件可移除；发送真实附件内容，不把文件名当作已读取内容。
- 保留当前 Codex 登录、会话及模型路由，不生成图片、不重复未知结果。

## Gate 2 — 素材库
- 独立原生素材窗口，入口紧凑，Pinterest / Eagle 两个来源。
- Pinterest 使用官方网页登录与收藏，独立持久 WebKit 会话，不读取密码或浏览器 Cookie；逐图导入需用户点击。网页不获得 Go/本地文件调用能力。保留来源链接。
- Eagle 默认连接本机只读 API，支持连接状态、关键词搜索、分页、图片预览及导入；读取原图后复制进当前画布，不改动 Eagle 库。未安装/未打开明确提示。
- 点击时确定导入画布；导入途中切换画布不串入其他项目。内容写入自有素材存储，可撤销、恢复并随备份保留。

## Gate 3 — 验证与交付
- 单元测试覆盖附件、API 解析、路径/URL边界、搜索分页及来源保留；Go test/race/vet/原生构建。
- 隔离数据实机验证助手关闭/动效/自动高度/附件、素材入口与失败反馈。Eagle 使用临时测试库验证；真实库按用户要求稍后连接。Pinterest 登录需用户本人，不冒充已登录。
- 更新本机安装前保存新快照，核对现有图片与项目完整性；不删除或覆盖生产内容。输出已验证项目和外部账号/应用限制。

## 本机认证与额度选择 · 0.6.8

- 在新用户目录、无系统 Codex 和 Node 的环境中，安装版能启动随包的官方 Codex，通过系统浏览器进行本人登录，并由官方运行时保存登录态。账号状态与生图权限分别检查。
- 设置分别保存生图、操作历史摘要的额度来源。已有用户默认沿用 Codex。OpenAI API Key 使用本机系统凭据库保存，API 请求直连 OpenAI。切换、重启、凭据失效和额度不足均按所选来源处理，已排队的任务保留提交时的选择。
- 验证文本总结、无参考图生图、多参考图编辑、失败后无重复提交。区分测试服务回执、实际账户认证与真实计费验收。
