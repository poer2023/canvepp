# Canvepp 原生设置窗口验收

## A 版与全局助手输入条

- 设置采用 A 版纵向清单，左侧沿用工作区导航，右侧在 850 × 704 与 640 × 430 可滚动。主题使用跟随系统、浅色、深色三张工作区缩略图，保留选中勾和键盘操作。
- ChatGPT 从 Codex 读取账户。未登录显示「登录」，已登录显示账户标识。授权期间保留取消和设备码，读取失败留在所属设置行。额度以图片、文字、订阅和插头图标区分选项，生图与摘要独立保存。
- OpenAI API Key 缺失时从「添加密钥」进入输入。保存时验证。已经保存的密钥通过「管理密钥」更换、检查或移除。移除在附近确认，错误保留在对应行。
- 三击空格呼出的助手使用同一套黑白工作面，顶栏标明 Codex 和当前草稿所属画布，正文全宽，附件、会话和发送位于底栏。核对焦点、Esc、草稿、换行、长文及附件布局，使用隔离资料库和账户样本。

macOS 隔离窗口验证了主题切换、登录按钮和样本邮箱两种账户状态，以及密钥编辑时的输入焦点。助手由工具栏和 ⌘⇧Space 打开后自动聚焦，Shift＋回车可以换行，Esc 隐藏后再次打开保留两行草稿。三击空格的时序由单元测试覆盖，系统级物理按键另需验证。验收完成后已退出临时应用。

## 独立窗口合同

1. **参考和范围。** 现场查看本机 Alma 设置窗口的系统按钮、分组、文字按钮与选择器，并核对 T3 Code 的设置行、说明和控件布局。仅改设置窗口与它直接使用的控件、状态和系统对话框归属。[T3 Code 设置布局](https://github.com/pingdotgg/t3code/commit/2e39f1d7dec44c98a4cabdaf99d3d99209f770c0)
2. **系统窗口。** 设置在画布上方独立打开。整个系统标题栏可拖动，左侧菜单的空白处也可拖动，分类按钮负责切换内容。macOS 使用左上的系统窗口按钮，Windows 使用右上的系统窗口按钮。拖动可超出画布窗口，边缘可调整大小。关闭只退出设置，Esc 和打开设置的快捷键仍可关闭。同次运行重开沿用位置和尺寸。
3. **设置内容与验证。** 右侧直接进入第一个分组。通用、数据和快捷键使用独立滚动区。操作按钮用清楚的动词，主题与额度用选择器，密码输入有边界。连接、凭据、权限和备份结果显示在所属设置附近。检查浅色和深色、常用与最小窗口、拖动、缩放、切页、返回工作区和 Windows 构建。使用隔离资料库，不发起实际登录和生成。

## 上一轮独立窗口验收

macOS 在同一实例内打开独立的 850 × 704 设置窗。依次拖动菜单上方的标题栏、内容上方的标题栏和菜单空白，设置窗跟随鼠标。第二次拖动越过了画布窗左边界，画布窗坐标和尺寸保持不变。左上系统关闭键只关闭设置，重开恢复窗口位置和尺寸。用系统放大键放大后可恢复原尺寸。窗口边缘的自动化拖动未取得尺寸变化。[窗口坐标记录](../artifacts/native-settings-window-20261118/macos-window-geometry.json)

通过左侧菜单打开数据页，取消「选择备份位置」后回到设置窗。主题选择器展开后按 Esc 收起，焦点留在设置。另用原生渲染检查深浅主题，用 640 × 406 的内容区模拟最小设置窗并验证表单和滚动。`go test -race ./...`、`go vet ./...` 与 Windows x64 交叉构建通过。系统窗口控件的实机验收在 macOS 进行。[浅色表单](../artifacts/native-settings-window-20261118/settings-light.png) · [深色表单](../artifacts/native-settings-window-20261118/settings-dark.png)

## 上一版应用内弹窗的实测


用隔离资料库验证了 1000 × 680 浅色窗口和 1440 × 900 深色窗口。浅色窗口从标题移动后可缩到 580 × 350，快捷键页可滚到底并拖动滚动条回到页首。从右边缘放大时只改宽度。深色窗口可从左侧设置标题移动，并从左上角放大。点击紧贴边框外侧的遮罩仍可关闭弹窗。

原生交互测试覆盖四边和四角、边界、滚动条、遮罩、Esc，以及重新打开时的位置和尺寸。通过 `go test -race ./...` 和 `go vet ./...`。实机验收使用单独签名的 macOS 测试构建。
