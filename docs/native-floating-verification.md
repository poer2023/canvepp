# Canvepp Native 0.4.2 验收记录

日期：2026-11-06。环境：macOS arm64 / Apple M4 / MyGo 0.7.4。范围仅 native/。

## 已实现

- 图片设置从左侧导航移入 320px 悬浮面板。标题拖动，靠近边缘 28px 内松开吸附，左右/下方留 12px，上方留出透明窗口拖动区域。支持自由位置、角落停靠、收起/展开/关闭，布局独立于画布后台保存。
- 左侧保留画布、历史、回收站。左下角打开独立设置页；Codex 检查/登录、备份导出/导入、快捷键集中于此，Cmd+, 可切换。
- 图片圆角、细边框、克制选中态；外置图标工具条。来源连线保持右出左入，选择/悬停时强调关联关系。保留 GPU 折线绘制与可见图片缓存。
- 选择图片不再切换左侧历史；面板标题之外的控件不会触发拖动；面板滚动不会缩放画布，底部停靠时缩放与撤销工具避让。

## 性能边界

本次 62 个原生帧样本包含启动、面板、设置与系统目录选择器操作：中位数 0.9ms，p95 14.5ms。最大 384.6ms 发生于首帧 GPU 管线初始化，首次展开面板 20.0ms、首次设置页 15.4ms；不将这些结果表述为固定帧率或完全消除卡顿。GPU 预热后的拖动帧多数在 1ms 左右。

500 张选区同步约 2.64µs / 0 次分配；保持原有无逐帧卡片复制路径。头部无持续动画，自动化验证空闲时不继续请求帧。headless 基准不是 Metal FPS 测试。
