# Spatial 画布首轮验收合同

依据：`docs/CODEX-REPRO.md` §2、§4.1–4.3、§5.1–5.5、§6、§7；公式仅参考 `MotionKit.swift.reference.swift`。继续使用 MyGo + Go 原生 UI / Metal，不引入 Swift 或 Web 画布。

## Gate 0 · 对齐
- 已检查当前原生画布、源码、文档和独立验收副本。统一 `SpatialTokens`；弹簧原始参数原样记录，通用 DBL_MAX 在 Go 数值求解时采用文档 §3.1 明确允许的临界阻尼实现。
- 当前用户行为优先：滚轮和捏合缩放，空格 / 中键平移；图片原样显示，透明图仅 hover / selected 显示棋盘格；卡片操作在图片外。

## Gate 1 · 实现
- 隐藏标题栏、交通灯、原生磨砂背景，内容内缩 8–12、画布圆角 18。浅/深画布使用参考 palette。
- 图片卡半径 16、柔软低不透明度阴影；normal / hover / selected / focused / dragging / deleting。hover 阴影、边框，选中 1.04 / 2pt，拖动层级抬起；删除淡出到 scale 0.9，模型立即可撤销并保留回收站。
- 拖动直接更新位置；4pt 点击阈值；松手速度采样、24/1.6/0.1/v0=16 惯性、边缘 / 中线吸附。移动及后续惯性为一次可撤销操作。
- 图片尺寸手柄按原比例缩放，仅改变画布显示尺寸；最小尺寸橡皮筋、尺寸吸附、尺寸标签、整数落位及一次撤销。
- 缩放 20%–400%，指针锚点不漂移；按钮与适应画布为相机弹簧；缩放期间复用低级缩略图、关闭昂贵阴影；双击空白新建。
- 按压 .9 / 50ms；无活动时停止动画调度，支持减少动态效果。字体按 Unica77LL / Eina03 / Volkhov 名称选择，未安装使用系统兜底，不随包复制第三方商业字体。

## Gate 2 · 验证
- 精确参数、数值稳定、可中断动画；指针拖动直达；松手惯性、撤销/重做、保存及异步回图不互相覆盖；尺寸与缩放边界。
- 1440×900、1000×680 原生窗口：状态、吸附、缩放、搜索展开/折叠及实际 Pinterest 网页在右内容区。用当前数据副本，生产原图不做验收删除。
- Go 测试、race、vet、原生构建；实际窗口截图与帧记录。CPU 绘制耗时只报告为本地指标，不当作远程手感或完整端到端 60fps 证明。
- 安装前备份应用与数据；核对业务表及原图完整性。保留 Pinterest 真实账户与用户远程拖动手感的未验收边界。

## 不在本轮
笔记/待办/叠卡/文件夹/付费墙、全屏卡片变形转场。§7 中这些独立组件不冒充通过。原有 Pinterest 右侧网页和搜索图标化继续完成，不顺带改变授权方式或生成路由。
