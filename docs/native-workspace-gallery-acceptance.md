## 全部图片 B 实装

- 使用 4 pt 间距的齐边拼排，普通图保持原比例，5:1 及以上横图占一整行。细长图有最小点击区域，最长边不超过 64 px 的小图最多放大两倍。复用页头、搜索和排序控件。只构建近处可见的图块。
- 单击图片只选中。选中后按空格使用现有原图预览，Esc 或关闭按钮回到图库，保留选择与滚动。搜索框继续接收空格。右键可定位画布、移动到其他画布、在 Finder 中显示和移入回收站。
- 跨画布移动保留原始文件，来源与目标同时保存。已有共用引用保留。删除复用回收站，支持恢复。用独立资料库核对 6:1、12:1、1:6 和相差 20 倍的方图，并走完预览、定位、移动、Finder 和删除恢复。

Mac 实测使用 31 张独立素材。单击后图库保持打开，空格进入原图组件，Esc 将焦点交回选中的缩略图。Finder 选中 4800 × 800 的图库原文件。右键把该图移到另一画布，再定位、删除并从回收站恢复。重开后目标画布仍有该图，图库回到 31 张。窄窗下超宽图前由邻图补齐。原生回归覆盖明暗视图、版本独立回收、共用原图和事务回滚。全量 Go 竞态测试、go vet 和 Windows amd64 构建通过。本机保留一个新版 Mac 验收窗口。[原生排版与选中态](../artifacts/gallery-variants-20261119/native-pictures-b.png)

## 原有全库验收

以 11 月 16 日的三张截图为基准，在原生应用 1000 × 680 和 1440 × 900 窗口检查以下行为。

- 灰色窗口顶栏只设一组标签，加号可打开 Pinterest、Eagle、图片历史和操作历史。重复选择激活已有标签，关闭后可切回其余页面。右栏第一行提供当前页操作。保留可拖动区域，按钮避让 macOS 交通灯和 Windows 系统窗口键。Pinterest 网页内可登录、查看收藏和拖图，应用工具栏省去重复的登录、收藏和内置网页切换。
- 图片面板吸附时四边均留 12 pt。设置移除素材库，主题采用扁平矩形预览，常驻内容以标题、控件和必要的值为限。API Key 提供掩码输入框，操作结果、授权设备码可获取。
- 左侧固定菜单打开「全部画布」和「全部图片」，瀑布流占据主内容区。画布封面打开对应画布，图片可预览或定位。切换时保留画布和已打开的侧栏标签，回收站保持独立。
- 检查标签、分隔条、系统窗口键的实际位置与可点击性，明暗主题、窄窗和滚动后的画廊，以及已有设置、账户和画布数据。使用原生界面测试和桌面截图核验。

## 本轮验证

- macOS 的 0.6.9 独立测试窗口导入了 5 张已有画布。实际查看了 23 张图片的瀑布流、三张主题预览卡和密钥输入框，从灰色顶栏打开包含四项的系统菜单，选中「操作历史」后确认右栏和画布同时可见。
- Windows 测试机 .22 通过安装包升级到 0.6.9。核对了安装程序与已装程序的 SHA-256、版本、桌面和开始菜单快捷方式。在已装应用中打开了两种画廊和设置，截图保存于 native/build/verification/0.6.9。
- macOS 全量 Go 竞态测试及 go vet 通过。Windows 原生测试覆盖系统窗口键避让、多标签切换、四边吸附、主题卡、密钥输入、127 张图片的瀑布流滚动与定位、Pinterest 拖放数据和已授权视图的恢复。
- 这轮没有重新进行 Google 授权，也没有用真实账号在 Windows 前台重新拖入 Pinterest 图片。没有调用付费生图或摘要。
