## 实现

- 画布与历史搜索使用统一的无硬边框浅色搜索框；设置按通用、数据、快捷键整理，操作与说明对齐。
- 大图预览利用整个内容区，等比显示、无棋盘格，保留原有缩放与移动。透明图在画布默认不填底，只在悬停/选中时绘制棋盘格。
- 回收站增加单项永久删除。数据库事务、删除标记、旧保存/备份导入防复活、共享素材/后代来源保护；撤销只移除已永久删除的节点差异，不破坏同一操作中的其他节点。
- 右下角操作日志记录人话动作。连续输入合并、拖动结束记录一次，与画布保存保持一致；生成及取消结果有持久回执。最近 500 条分页读取，可继续加载更早操作。
- 按需用本机 Codex 的 `gpt-6-luna` 总结最多最近 100 条。摘要保存模型、范围和指纹，保留事实记录；无模型时不静默改用其他模型。
- 单行流光助手，回车发送、Esc 收起；每张画布延续同一 Codex 会话，可通过输入条跳转到完整会话。只提供文字建议，不执行画布修改或生图。`⌘⇧空格` 和右下角按钮可唤起。
- 三击空格使用只读系统事件监听，识别完整短按、打断和时间，不存输入文字、不拦截其他应用按键。系统权限状态、开关及设置入口可见。
