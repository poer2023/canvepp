# 桌面工作流验收

目标是让 Canvepp 按 Windows 后台工具的方式运行，同时缩短批量生成的等待并减少 Codex 会话列表里的生图记录。

1. 主窗口关闭后隐藏，资源管理器预览与助手继续工作。左键托盘图标和再次打开 Canvepp 都恢复当前窗口。右键托盘的「退出 Canvepp」走保存与退出流程。
2. 三击空格在普通 Windows 桌面窗口可唤起助手，输入焦点落在编辑区。检查 Canvepp 各页、资源管理器的文件列表与地址栏、文本编辑器、浏览器地址栏与正文、终端和普通对话框。连击期间切换窗口、长按、带修饰键、单击和双击不触发。检测到游戏时跳过，正常按键保持原用途。系统安全桌面和无法识别的游戏单独记录。
3. 空格预览按文件比例取尺寸并限制在文件所在显示器的工作区内。小图按原像素大小，大图等比缩小。文稿页面目标高度为工作区的四分之三，横向空间不足时进一步等比缩小。验证长图、宽图、小图、纵向及横向文稿、连续滚动至后续页，以及关闭后返回资源管理器。
4. 多张时在生成按钮上方提供「并行生成」开关。按下生成时固定这一批的模式，关时逐张，开时同时提交并限制运行数量。保留占位、图片版本、取消及单张错误反馈。
5. 订阅生图使用临时 Codex 会话。画布、原图和任务回执仍保存在本地，已存在的历史会话可以查询。用随安装包提供的 app-server 验证临时会话未进入普通列表，再用受控输出验证多张生成与故障恢复。

验收沿用原生界面规范、当前账号及模型配置。用隔离资料库和可复现的测试文件覆盖 Windows 实际窗口，记录真实交互与模拟条件。
