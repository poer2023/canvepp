# Pinterest 网页与图标搜索 · 0.6.3

本次 Windows 验收以画布右侧的收藏为终点。完成账号连接后 Canvepp 必须回到前台，右侧显示该账号的收藏，并能通过拖放在当前画布生成带 Pinterest 来源的图片节点。正常退出再启动，同一测试数据目录能恢复登录和已打开的收藏栏。分别记录真实账号与模拟服务的结果。

Windows 网页模式使用本机 Chrome 已有的 Pinterest 会话，在右侧显示官网收藏页。用真实网页检查账号标记、Pin 列表、实际拖放入画布、收起与切换以及应用重启。无需开发者应用或扩展；可选的 API 授权单独验收。

Windows 已安装 Chrome 时，默认右栏复用该浏览器的 Pinterest 登录态。登录按钮在右栏的原生子窗口中进入 Pinterest 官方页面并指定登录后前往“已保存”。Google 账号选择由 Chrome 和网站处理。切换 Eagle 或离开右栏时隐藏专属窗口，退出 Canvepp 时关闭它。无 Chrome 时保留原内置网页，官方 API 收藏入口独立保留。

- 打开素材库的 Pinterest 默认页就是 Pinterest 官方网页，优先在右侧使用 Chrome 网页，内置模式使用系统 WebView。左侧目录保持可用；不要求先配置 App ID，也不另起素材窗口。网页提供浏览、返回、刷新与图片导入；既有官方授权收藏功能保留为次级入口，浏览器授权不宣称与 WebView 自动共享登录 Cookie。
- 画布、历史、Eagle 和授权收藏的应用内搜索默认只显示无边框放大镜。点击展开并聚焦输入，提供短暂展开动效；空值失焦收起，Esc 收起且保留非空筛选的标记，清除操作立即刷新结果。尊重减少动态效果，空闲不持续重绘。
- 检查 1440×900、1000×680：实际 Pinterest 网页位于右侧，页面切换无遮挡；搜索展开、输入、清除、收起、中文输入及筛选保持正常。隔离数据验证导入和原始来源记录，生产数据备份并校验。
- 保持原有画布、图片、回收站及日志；不代填 Pinterest 凭据，不把登录页当作已登录收藏验收。Pinterest 页面属于第三方内容，不开放本机 Go/RPC 桥接。

此前的 2026-11-16 Windows 测试（仅浏览器登录入口）。素材库登录提示已显示时，点击表单中的 Google 入口成功前置 Chrome。该机器日常使用的 Chrome 直接进入已有会话的 Pinterest 首页，可见个人资料、消息和通知。用独立的空白 Chrome 配置在 Pinterest 登录页继续选择 Google，出现 Google 官方账号输入窗口。实测到账号输入为止。Windows 上 14 项相关测试及本机 Go 竞态测试均已通过。


### Windows 右栏回跳与重启复测

在 `.22` 的独立数据目录运行带 `pinterestqa` 标签的程序，使用本机模拟授权服务和一张 PNG。用鼠标在默认 Chrome 中点击授权，前台采样记录到 Canvepp 自动重新激活。右侧出现模拟图板和图片，向左拖放后，SQLite 中保存了一个节点和一个具有 Pinterest Pin 来源的素材，保存的原图 SHA-256 与测试输入一致。

关闭并重新启动同一数据目录后，新的进程自动打开右侧收藏，重新取得图板与图片。该次启动记录两次 API 读取和零次授权兑换。Windows 运行的 12 项相关测试通过，包括跨进程恢复已轮换的令牌。本机构建通过 Go 竞态测试和 vet。

正式 Windows 测试包使用 Pinterest 官方服务。模拟服务仅验证 Canvepp 的回调、前台激活、右栏、拖放与凭据恢复。此 API 路径读取真实私人收藏时需要配置 Pinterest 应用并取得账号持有人的授权。右栏官网模式直接使用网站登录态。


### Windows 官网收藏实测

旧版使用独立的 Chrome 窗口覆盖右栏。用户通过 Google 登录后，该窗口停在 Pinterest 首页并偏移到画布上。更新前比对了 Pinterest 个人资料入口，确认用户刚登录的账号与正式测试版右栏使用的账号一致，随后关闭旧测试窗口。

修正版在画布右栏创建 Win32 子窗口并挂载 Pinterest 官网页面。对已登录账号再次点击素材库的登录按钮，可在同一栏返回“已保存”。开发者应用、扩展和调试端口均非此路径的依赖。新版实测复用了现有会话，未重复从退出状态输入 Google 凭据。

在 `.22` 用系统鼠标将真实收藏拖入测试画布，节点从 4 个增至 5 个，新增素材保留 Pin 链接且图片已写入磁盘。调整分隔线后，网页跟随右栏改变宽度。切到 Eagle 会隐藏网页，切回恢复同一个子窗口。

正常退出后，旧网页随主窗口关闭。从测试版快捷方式重新启动，新进程自动恢复右栏收藏和 5 个画布节点。重启后用 Windows 窗口 API 确认网页是 Canvepp 主窗口的子窗口；实测网页内容与右栏可用区域的左、上边缘和宽高均一致。Windows 运行的 13 项 Pinterest 相关回归测试通过。

### Windows 右栏交互性能验收

在 `.22` 同一测试画布和登录会话上，对比点击登录至官网收藏可用、真实 Pin 松手至画布首次反馈和新增图片保存的耗时。重复测量并核对来源、节点数、落点和重启后的会话。已显示收藏时保留当前页面，首次登录仍通过 Google 官方页面。拖入时尽早反馈，下载失败能撤掉临时状态，后台任务仍归属松手时的画布。

在同一已登录的 Windows 测试会话上，收藏页点击登录后检测到可用 Pin 的中位耗时从 6033 ms 降至 58 ms，三次均保留同一个网页窗口。打开单张 Pin 再返回自己的收藏耗时 437 ms。系统鼠标拖放后，画布落点区域首次画面变化的中位数从 268 ms 变为 41 ms，节点持久化中位数从 435 ms 变为 562 ms。各组 3 次，原图字节与 Pin 来源已核对。重启后右栏继续显示收藏。测速沿用了已登录账号。
