# 原生画廊视觉精简合同

- 画廊图片去掉外卡片边框、白色包裹、内边距和铺底色块。保持原始比例，透明图片仍有局部棋盘背景。
- 图片下方只留一行低对比度名称和小图标；移除第二行画布名称。完整文件名、所属画布通过悬停提示查看。
- 回到来源画布、恢复、返回当前画布均使用无文字图标；悬停显示短说明，点击仍执行原动作。操作位于图片外。

- 不修改图片、历史、生成参数、来源关联、数据结构和保存机制。无新增生成、登录、清空操作。
- 验收 1440×900、1000×680，确认无图像拉伸、无卡片边框或多层底色；检查图标点击、提示、预览、返回及排序分组，保留键盘和辅助功能名称。沿用现有回归测试，不为纯样式添加实现镜像测试。
- 先在独立副本操作，再更新本机应用并校验生产数据；截图记录最终样式。
