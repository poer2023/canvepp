# 原生图片抽屉验收

2026-11-06。Canvepp Native 0.4.5 已构建、签名并更新到 `/Users/hao/Applications/Canvepp Native.app`。依据 [验收合同](native-image-drawer-acceptance.md)。

## 完成内容

- 一个 320 DIP 白灰悬浮组件，上方来源，下方创作；点击摘要以 200 ms 位移、透明度切换同一组件的内容。保留拖动、吸附、收起、关闭。系统减少动态效果时取消滑动。
- 来源来自资产版本和原生／旧版任务快照，显示原始提示词、按原顺序排列的参考图片、时间、目标和实际尺寸。上传图片不补造提示词；快照缺失明确显示未记录。
- 创作按实际参考版本查询后续任务，记录不依赖连线或节点是否仍在画布。可展开原提示词、查看结果大图、定位原画布图片。没有后续记录且没有已保存草稿时隐藏创作区，点击创作图标开始。
- 来源与草稿独立；切换和查看记录不会修改历史。沿用前若会替换现有非空草稿，显示组件内的保留／替换操作。旧草稿、像素和数量保留。
- 图片悬停的编辑入口直接打开创作表单。保留比例宫格、自由像素、宽高联动和 1–4 张选择；窄窗口在表单内部滚动，生成按钮保持可见。
- 后续记录使用虚拟列表，图片只在可见范围进入解码队列；来源索引在任务或资产改变时重建，拖动画布不重建。

- `go test -race ./...`：通过，12.627 s。覆盖来源不可变、多参考顺序、不同图片版本、节点与连线移除后的关系、旧快照、参数草稿、沿用保护、结果定位、窄窗口、减少动态效果及静止停帧。
