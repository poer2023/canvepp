# 原生悬浮图片设置与设置页验收合同

日期：2026-11-06。范围为 native/，沿用 MyGo 原生渲染，不修改旧版 Web 项目或生成服务。

## 视觉与布局

- 当前图片设置从左侧导航拆为画布内 320px 白色悬浮面板，标题区拖动；默认右上，靠近四边松手后吸附，保留边距。支持收起、关闭、重新打开，并记住位置。窗口缩小后面板仍可操作。
- 左侧保留画布、历史、回收站。左下角设置入口打开独立页面，含 Codex 连接、备份与导入、快捷键。返回时保留画布视角与选区。
- 参考 Lovart 官方界面的中性灰白、克制边框与上下文工具；图片本体无常驻标题，工具在图片外；选中态清晰，连线只从右侧到左侧，相关关系强调，其余关系降低视觉权重。
- 参考证据：https://www.lovart.ai/ 与 https://www.lovart.ai/docs/edit-your-design/customize-your-canvas 。吸附行为是针对本产品新增的设计。

## 行为与性能

- 面板拖动不移动图片、不改变选区；输入、按钮和滚动不穿透至画布。画布滚轮仍以指针为中心缩放。
- 四边吸附、自由位置、关闭重开、重启恢复、1440×900 与 1000×680 均验收。
- 单图与多图参数、生成数量、历史、回收站继续可用。设置页不自动登录或触发生图。
- 保留现有 GPU 连线与缩略图缓存路径；无持续刷新或拖动时磁盘写入。新增状态仅在结束交互时保存。

## 内容与证据

- 原始图片、节点、提示词、连线、历史与回收站不迁移不清空。实际交互先在独立数据副本测试；安装前保留原程序与数据库备份。
- 必须包含原生 UI 回归、构建、race/vet 检查与真实窗口截图。实际 GUI 验证面板拖动吸附、设置返回、最小窗口布局，并记录未完成边界。
