# Pinterest 浏览器授权与原生素材库 · 0.6.1

目标：使用本机默认浏览器登录并授权，成功后自动回到 Canvepp；收藏和图板以清晰、顺滑的原生界面浏览并导入当前画布。保留既有画布、素材、Eagle 接入、助手及模型路由。

## Gate 0 — 现状与展示方案

- 已核对当前实现和用户截图：整页 Pinterest 嵌入独立 WebKit，未接 OAuth，因此浏览器登录无法回到应用。
- 改为原生连接状态页、图板目录和分页图片网格；不再嵌入登录网页。图片展示优先，浅灰背景、无多余卡片边框、图标操作与悬停提示。
- 官方 OAuth 需要已注册并获批的 App ID、Secret、精确匹配的 Redirect URI。开发者配置独立于日常连接操作；未配置时明确状态，不打开无效授权链接、不假装已连接。

## Gate 1 — 应用侧接入

- 点击连接通过系统默认浏览器打开官方 OAuth。只读权限，随机 state、本机回调、超时/取消/拒绝、单次兑换、过期刷新、退出连接。
- 授权成功保存到系统密钥链，自动前置素材窗口并加载原生内容；密码不经过应用。配置与令牌不写入画布数据库、备份、日志或构建产物。
- 图板及图片按官方游标分页，保留加载/空/失败状态，提供大图预览、原网页入口和一键导入；读取原图时绑定点击当时的画布，保留来源与撤销。
- 缩略图后台限量解码，滚动网格虚拟化；只有可见页面的图片留在内存，页面/账号切换取消旧请求，旧回调不污染新状态。

## Gate 2 — 验收与交付

- Go 测试覆盖 state/回调/拒绝/重放、令牌刷新、分页与图板图片、取消旧请求、来源导入与内容保留。使用标注清楚的本机模拟授权服务验证应用流程，不能冒充真实 Pinterest 授权。
- 原生窗口至少 1040×740、700×460 验证未连接、等待浏览器、连接失败、图板/图片、预览与导入；保留截图和回执。
- 真实 Pinterest 账号验收依赖获批开发者应用，由用户在本机配置凭据。没有配置时仍完成代码、测试及可查看的界面，明确外部阻塞。
- 最终构建验证、安装前备份及内容比对；更新后恢复既有输入监控授权。没有新需求、失败或风险，不扩大全量回归范围。

不包含：自动注册/转换 Pinterest 商业账户、接受开发者条款、发布云服务、把应用密钥打进可分发安装包、读取浏览器 Cookie、绕过 Pinterest 访问限制、修改或删除 Pinterest 内容。
