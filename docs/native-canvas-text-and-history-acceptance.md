# 画布文字工具、图库时间线与操作历史

1. 对照截图调整原生设置和图片详情。设置正文在右侧内容区水平居中，保留 680 pt 上限、侧栏位置和独立滚动。图片来源、尺寸和操作放在紧凑的内容区，创作从操作按钮进入，图二的创作参数和草稿流程继续可用。
2. 全部图片可以切换齐边拼排和时间线。时间线沿用全部画布的日期标题、封面卡片和最近优先顺序。两个布局共用搜索、选中、空格查看原图与系统右键菜单，并分别记住滚动位置。
3. 画布文字使用工具按钮或 T 放置，可输入多行、再次编辑、移动、撤销和保存。操作历史从窗口顶栏打开，在右侧栏按日期展示已存记录，可定位图片、文字和回收站条目。历史数据只读核对，界面用隔离资料库验收。

检查宽窄设置、两种图库布局、已上传图片和创作面板、文字新增及重新打开，以及含早期操作记录的画布。使用原生渲染与交互测试和实际桌面窗口，另验证 Windows 构建。

## 验收结果

- 只读检查本机安装版的默认资料库，查到 6 张画布的 16 条原有操作。12 条移动、2 条编辑、1 条画布操作和 1 条新建记录仍可从数据库读取。
- macOS 隔离窗口通过系统窗口菜单放大设置，正文与右侧内容区的左右留白对称。自动测试覆盖 640、850、1440 和 1800 pt。
- macOS 全部图片从齐边拼排切到时间线，确认今天、近 7 天和更早的三个分组均显示真实图片。选中图片后用空格打开原图。另在原生渲染测试中切回齐边拼排并核对选中状态。
- 从操作历史定位本地图片，打开来源面板，核对标题、时间、像素、下载、查看大图和创作入口。点击创作后显示原有提示词和参数行。操作历史展示按日期分组的旧移动记录。
- 文字工具在放置后聚焦正文。macOS 实测实键输入、粘贴两行中文、双击编辑和保存。退出后只读确认编辑后的文字和记录已写入隔离资料库。原生回归另覆盖撤销、重做、回收站恢复及重新读取。
- macOS 通过原生竞态回归、静态检查和签名验证。Windows x64 通过编译与静态检查。此前和本次的验收实例均已退出。
