# Native workspace tools · 0.5.0

目标：保留现有画布与图片，精简原生 UI，并补齐可追溯的操作日志、回收站永久删除和单行 Codex 助手。

## Gate 0 — 已确认范围
- 实机为 MyGo 原生 0.4.8；现有搜索有硬边框，设置为厚卡片，大图与透明图片常驻棋盘格。
- 基线与可写验收副本：`artifacts/native-workspace-tools-20261106/`。所有删除、生成日志与助手发送测试在副本，生产回收站不删除。
- 助手仅一个单行流光输入条，三击空格唤起、Enter 发送、Esc 收起；不添加聊天面板。延续每张画布的 Codex 会话。

## Gate 1 — 实现
- 所有侧栏搜索统一低对比、无硬边框；设置改为有层级的连续分组和对齐行，短文案、13px 主文字。
- 预览内容区尽量铺满、保持图片比例，背景与容器一致，无棋盘格；保留放大和拖动能力。画布透明图仅 hover / selected 显示棋盘格。
- 回收站单项永久删除有清晰确认，删除后不能从撤销或重启复活；共享素材不误删。
- 操作事件持久化、与保存一致、拖动结束只记一条；新增/导入/复制粘贴/删除恢复/修改/生成/撤销重做可追溯。右下按钮打开日志。旧项目明确从升级后开始记录，不编造旧操作。
- 日志以事实模板直接可读；按需通过当前 Codex 订阅轻量模型总结，保留原始事件、模型和覆盖范围。优先 model/list 中可用的 gpt-6-luna，失败不冒充 AI 总结。
- 助手后台接 Codex，单行输入、可继续同一会话。只按键类型与时间识别三击，不保存全局键盘内容；权限状态和开关位于设置页，未授权时保留应用内入口。

## Gate 2 — 验证与交付
- Go 单元/竞态/vet/build；重点覆盖操作合并、保存队列、删除共享资源/旧快照/撤销、三击检测、会话延续与失败状态。
- 原生 GUI 在隔离副本验收：搜索、设置、透明图三态、预览、删除确认及重启、日志与单行助手。真实模型用最小文本验收，不生成图片。
- 构建签名包、更新本机安装、对比生产数据/图片完整性，记录截图及验证结果。系统监听权限仍由用户控制；不能验证的全局触发明确报告。

非目标：不修改现有图片任务路由、凭据或模型配置，不调用独立 API/Magpie，不回写旧图，不优化其他 web 版本，不删除生产数据。

## 全局快捷键修复补验
- 用户实测：输入监控已开启，但其他应用中三击空格没有出现输入条；不能以权限已授予代替触发成功。
- 检查事件监听、三击识别、主线程调度和窗口显示的完整链路。临时诊断仅记录事件类别及时间，不记录字符或其他按键内容，默认关闭且限时。
- 修复后从其他应用三击空格应出现唯一单行输入条，立即可以输入，Esc 收起；长按、空格拖动、其他按键打断不得误触。
- 保留用户当前画布、图片、回收站与会话；更新应用前制作新快照，不恢复旧数据覆盖现状。
