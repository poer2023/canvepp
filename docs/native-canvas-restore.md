# 画布还原至 0.6.2

以 0.6.2 原生安装包和该版本的画布源码为基准。右侧画布恢复原先的 6 pt 边距、10 pt 圆角、底色、图片大小与选中样式，以及原有的移动、框选、连线和缩放行为。窗口上方保留拖动区。新版素材页和图标搜索独立保留。

用同一份数据副本分别打开旧版和还原版，比较画布和图片，检查选中后的边角拖动、撤销、画布缩放与适应。对 0.6.3 保存过单图缩放的画布验证旧版显示尺寸，同时保留文件中的元数据。安装前后只读核对生产画布、原图、生成记录和回收站。

2026-11-07 已安装 0.6.4。用「Codex 原生 · 实际生图验收」在 1440 × 900 窗口、48% 缩放下与原版比较：未选中时的两张示例图片、上下边缘，以及选中后的悬浮设置区域与旧截图像素一致。从已放大过的图片右下角拖动后能一步撤销，节点与连线数据逐项归位。画布放大按钮从 48% 到 60%，适应后为 87%。同一窗口仍能打开 Pinterest 和 Eagle 素材页。

原生模块通过 `go test -race ./...`、`go vet ./...` 和 macOS 构建签名检查。正式安装并重开后，SQLite 完整性检查通过，业务表和 18 份原图的 SHA-256 与更新前一致；其中包含 6 张画布、23 条图片记录、14 条生成记录、11 条回收站记录。已恢复当前安装包原有的输入监控授权。实机截图、像素对照及安装前后核对结果在 [验收目录](../artifacts/native-canvas-restore-20261107/)。
