# 图片来源与创作抽屉

2026-11-06，基于现有原生应用的悬浮图片设置组件。

- 单个白灰悬浮组件，上方「来源」，下方「创作」。两区为可点击的摘要入口，同一时间展开一侧内容；来源向下、创作向上滑入，避免独立弹窗或多层卡片。
- 来源读取图片版本与生成任务的不可变快照：上传／生成方式、原提示词、参考图片、时间、目标与实际尺寸。没有原提示词时不从当前输入框推测。
- 下方显示该图片版本参与的后续生成。没有记录且未开始创作时隐藏该区；图标入口可开始创作。空白图片与多图选择直接进入创作。已有草稿完整保留。
- 创作抽屉可查看历史结果、定位图片，并填写下一次提示词、比例／像素和张数。沿用来源或历史提示词须明确点击，不能自动覆盖已有草稿。
- 来源和后续记录不依赖画布连线。此次不增加剪线功能，不删除或迁移图片、任务和旧输入。
- 320 DIP 宽，16 DIP 外圆角，细分隔线、轻阴影、无文字小图标与悬停说明；最多 220 ms 动效，静止无持续重绘，遵从系统减少动态效果。
- 保留拖动、吸附、收起、关闭、键盘输入、滚轮隔离；1440×900 与 1000×680 内可访问全部内容。
- 验收：不可变来源、多版本／多参考关系、旧快照缺失、未生成和无后续记录、切换保留草稿、已有草稿沿用保护、结果定位、动效停帧、数据原样保留。真实 GUI 在独立数据副本验收，再更新本机应用；不调用生图或登录。
