# Canvepp Native 0.4.3 导航与画廊验收

日期：2026-11-06。合同：[native-gallery-acceptance.md](native-gallery-acceptance.md)。本轮只修改 native/，保留 Web 版及所有既有用户数据。

## 已交付

- 左栏顶部移除当前画布标题、保存提示、新建图片和导入图片。画布名称仍可在目录右键重命名并按 Enter 保存。
- 标签下操作行：画布为新建画布＋搜索；历史为搜索＋排序，并可切换按时间／按画布；回收站为排序。
- 历史左侧仅展示分组和数量，右侧展示响应式图片网格。图片可打开原图预览，或回到来源画布并定位节点。旧版本不会自动替换当前版本；来源已删除时不会自动复原或复制节点。
- 回收站在右侧展示图片与占位图，可恢复到原画布。分组按删除日期，支持最近、最早和名称排序。
- 设置为一个图标＋文字按钮，统一点击与悬停区域。使用标准 Lucide 齿轮 SVG，ISC 许可随源码和应用打包。
- 网格虚拟化、目录缓存、仅在图片进入可见区域时请求后台解码；透明棋盘限制在图片实际区域。
