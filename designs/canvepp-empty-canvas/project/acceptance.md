# 空画布试稿验收

- 以用户截图与 Canvepp 当前界面规范为参考，范围为浅色桌面画布空态。
- 三张 840 × 624 画板共用白色点阵和中性扁平控件。各版均展示导入图片和新建图片。
- A 以紧凑图标为主，B 突出拖放提示，C 给两个操作相同权重。
- 控件具备可访问名称与悬停、键盘焦点反馈。文件选择、拖放和新建行为由正式应用承载。
- 使用 Baoyu Canvas 的 `check` 检查画板格式，通过对照预览检查构图和文字。

## C 版原生实现

- 空画布居中并列显示「导入图片」和「新建图片」。两块按钮同宽同高，使用主题的纯色表面和线性图标，窄画布下等比例收窄按钮宽度。
- 点击分别打开文件选择器和创建图片节点。沿用键盘焦点、快捷键气泡和画布文件拖放，按钮区域也接收文件拖入。
- 核对浅色、深色及窄分栏。空态随画布内容、选区手势或图片设置面板显示和收起。
