# 图片创作面板 · 五版对照

以 2026-11-19 的浮动图片创作面板截图和[现有界面规范](../../../docs/interface-design.md)为准。五张 Baoyu Canvas 画板只探索图片草稿的创作态。每版保留提示词、八种比例、自由像素、宽高、1–4 张、生成、移入回收站和面板收起与关闭。原生应用等选稿后再接入。

- A · 编辑器式。尺寸与张数贴在提示词底部，点开后就地修改。适合先写提示词、参数偶尔调整。
- B · 参数清单。比例、宽高和张数沿同一列对齐，宽高直接可改。适合每次都要精确设尺寸。
- C · 画幅卡片。四种常用比例用真实宽高的轮廓并排呈现，其他比例集中到「全部」。适合按构图挑画幅。
- D · 横向工具盘。提示词和参数并排，宽面板换取更少的纵向遮挡。适合宽屏画布。
- E · 双页工作台。提示词和输出参数各有一页，页底生成入口共享。适合在窄面板里分别处理两项工作。

直立面板宽 320 px，横向面板宽约 500 px。都用实色、细边线与既有线性图标。默认跟随系统，也可在画板的 Tweaks 中指定明暗。同一示例草稿便于比较，清空提示词后生成禁用。宽高仅接受 64–8192 px，固定比例随编辑联动，自由像素独立。生成和回收站只在画板内显示演示结果。

验收时在 Baoyu 中并排查看五版，并用 Play 验证提示词、比例、宽高、张数、生成反馈与双页切换。确认新画板与原空画布方案可分别访问。

## 本机验证

Baoyu 对照页显示五张画板。A 选择 16:9 后显示 1024 × 576，选择 3 张后可见生成预览回执，收起再展开保留提示词。B 改宽为 768 后固定 4:3 联动到高 576，改成自由像素后独立把高改到 920。C 直接切换 3:4 卡片并从完整菜单选择 21:9。D 用步进按钮增加张数后显示 2 张的回执。E 核对了切页保留草稿、空提示词禁用生成，以及深色预览。
